拾页 · Pagefold 0.4.0

安装扩展包 pagefold-chrome-v0.4.0.zip：
1. 解压压缩包。
2. 在 Chrome 打开 chrome://extensions，启用开发者模式。
3. 点击“加载已解压的扩展程序”，选择直接包含 manifest.json 的解压目录。
   扩展专用 zip 的 manifest.json 在根目录；完整源码包则选择里面的 extension 文件夹。
4. 点击工具栏中的拾页，或使用 ⌥ Shift P 打开工作台。

以后替换文件后，在扩展管理页点击“重新加载”，再刷新已打开的拾页页面。

常用项目：编辑项目、用途说明及细分；同一活动允许多个项目标签。
AI 分析：点击“AI 分析并更新”生成分类预览与独立活动路径，不移动或关闭页面。
统计总览：项目分布、重复页面、共同访问线索；不统计工作时长或效率。
移除工作空间：页面进入未分配，历史保留，底部可恢复分类。
Chrome 历史：AI 分析页按需读取，首次需允许可选 history 权限；仅导入本机副本。
切换线索：可以暂停；暂停后仍可通过历史与当前页面分析。
工具栏数字：普通非无痕窗口的页面数量，不含扩展页。

使用 AI 或 MCP 时，在完整项目运行 npm ci 和 npm run setup:mcp；
模型 API 需配置自己的本机密钥与模型，安装包不含密钥。MCP 使用 Codex 当前对话，不要求另配模型 API。
如当前 Codex 任务看不到新增 pagefold 工具，可新开任务加载工具列表。

实际跨窗口整理仍需预览后应用。恢复关闭的副本只能重新打开网址，不能还原未保存状态。
详情见 docs/projects-and-activities.md。
