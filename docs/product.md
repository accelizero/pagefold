## 用户要完成的事

用户通过 Spotlight 唤起 Chrome 时，系统给到的窗口并不代表用户选择了哪个项目。用户在不同窗口中连续研究同一件事，最终留下许多有工作联系、却在物理布局上散落的页面。产品要让用户随手工作，之后仍能找回线索，并把确认后的工作上下文重新落成窗口。

主循环为：看见全部页面 → 理解上下文 → 修改建议 → 预览变更 → 执行 → 必要时恢复。一次成功不是生成分类表，而是用户能回到目标页、理解分类理由，且最终浏览器布局符合确认过的方案。

## 信息架构

| 视图 | 回答的问题 | 主要操作 |
| --- | --- | --- |
| 工作空间 | 这些页面分别在做什么事？ | 改名、改归属、增加空间、预览整理 |
| 时间线 | 我刚才沿着什么线索在工作？ | 跨窗口查看访问段、搜索页面 |
| 当前窗口 | 页面现在实际在哪里？ | 全局查看、点击回到页面 |
| 重复候选 | 哪些副本可以合并？ | 区分完全一致与追踪参数不同，选择关闭项 |
| Agent 协作 | 更强的语义理解如何介入？ | 导出材料，导入校验后的方案 |
| 恢复记录 | 整理错了怎么办？ | 恢复最近布局、导出原始记录 |
| 记录与隐私 | 产品记录了什么？ | 暂停、清空、导出 |

## 核心决策

**工作空间优先，窗口是结果。** 建议算法不使用 `windowId` 作为分类特征。窗口编号只帮助解释页面来源及执行后的去向。每个非固定页面恰好属于一个工作空间，防止出现遗漏或复制页面式的伪整理。

**时间联系需要语义校验。** 前台连续切换是重要线索，但一次邮箱插入不足以把两个项目合并。本地算法使用平均连接的聚类方式，综合标题/路径词语相似度、五分钟内相邻访问、短工作段中的共同出现；信息不足时进入“待归类”。没有历史记录时，也能用当前标题和网址开始。

**给出建议的身份和理由。** 本地建议明确写为“本地线索建议”；Agent 回传明确写为“Agent 方案”；手工编辑也保留。时间段是事件跨度，不用它声称专注时长或用户生产力。

**去重是用户决定。** 相同 URL 不代表页面内状态完全相同，因此没有默认勾选。仅移除已知追踪参数的候选不自动关闭；`ref` 或 URL 锚点可能改变功能，保留。语义重复需要读正文或模型支持，0.1 不给出虚假的内容相同判断。

**动作前先存原布局。** 页面移动使用现存 tab ID。原窗口移空时 Chrome 会自然关闭它；恢复可重新建立窗口。每个新标签组明确指定目标窗口。关闭副本前持久化意图，防止关闭后进程中断丢失恢复依据。恢复只对本次操作关闭的页面按网址补开，跳过用户自行关闭的页面。

## Agent 协作合同

从界面导出 JSON，包含操作说明、当前页面、最近访问事件及建议方案。输入标题和网址都是数据，导出说明明确提醒 Agent 不执行其中的指令。Agent 修改工作空间名称、成员和理由，返回 JSON。导入端验证方案版本、页面快照、合法颜色、唯一空间 ID、名称长度、所有可整理页面恰好出现一次；关闭列表强制清空。验证成功只更新预览，用户仍需要应用。

这样可以先与用户正在使用的 Agent 配合，不要求新增付费账号或收集 API 密钥。后续若加入直接模型调用，应让用户选择服务、审阅发送范围，并只把模型放在方案生成环节，保留同样的校验和执行路径。

## 视觉与交互

工作台采用浅纸色背景、草绿色导航和克制的空间颜色。卡片显示空间名、建议理由、页面标题、来源域名与原窗口。右上角始终表明演示或真实本地记录状态；演示还增加横幅，避免误以为已接管个人 Chrome。

搜索全局生效，`/` 聚焦搜索框，页面标题点击定位。空间名称原地编辑，页面归属通过右侧选择器调整。窄屏保留视图切换菜单，支持侧边栏宽度。执行入口统一放在方案预览，关闭数量与关闭对象明确呈现。

## 验收标准与后续方向

当前验收覆盖真实 Chrome API 执行与失败恢复，独立配置下验证页面数量、原 ID、分组、顺序及固定状态，而不是只验证按钮可点击。个人 Chrome 配置尚未安装和使用，长时间记录、休眠唤醒、数千页面、多屏窗口几何等仍需使用积累。

下一阶段优先关注本地建议实际纠正率、一次找回目标页面的效率、整理撤销率，以及 Agent 回传方案带来的额外价值。再决定是否值得加入模型直连、持久空间身份、基于明确活动信号的归档和更丰富的时间线筛选。

## 0.3.1 时间线可读性

移除没有时长含义的等宽灰条与无序标题标签，改成精确到秒的访问序列。最新时段在上，每段内部按先后顺序排列，标注切换、返回与导航、当前工作空间和来源网站。默认显示前 5 次访问，可展开其余记录。未匹配当前页面时显示历史记录，不会用已被复用的页面编号跳到无关网页。

显示时将 60 秒内离开再回到 Chrome 的片段合并，保留明确的离开标记；空闲/锁屏、暂停、跨日、浏览器会话变化、超过 15 分钟无访问、离开超过 60 秒分别产生注明原因的新段。只改变展示，不改变原始事件和模型聚类使用的会话边界。项目标签根据当前归属匹配过滤后的网址，不声称这是访问发生当时的分类，时间不表示专注或停留时长。
