# AI 分类（0.4）

默认选择独立模型 API：点击按钮时读取标题、过滤查询参数与锚点的网址、常用项目、最近最多 20 段 / 300 次有序访问及上次分类，经本机 Native Messaging 服务发送到 用户配置的模型服务。模型输出分类与逐次活动报告，不提供任何工具。扩展校验每页唯一归属后写回预览；不会移动或关闭 Chrome 标签。固定页面不参与分类，手动改名/移入的页面归属保留。分析期间新增或导航的页面进入“新增待分析”；手动编辑会阻止旧结果覆盖。

不内置服务商、API 地址或默认模型，需由用户显式配置。模型 API 使用所选服务的额度，和 Codex 的对话额度分别计算。MCP 保留用于 Codex 读取正文、深入判断和按用户指令应用/恢复方案。

密钥由本机服务读取 ~/.config/pagefold/.env 中的 PAGEFOLD_API_KEY、PAGEFOLD_BASE_URL 和 PAGEFOLD_MODEL（也支持进程环境变量；旧版 LITELLM_API_KEY / LITELLM_BASE_URL 变量兼容保留）；不写入扩展、浏览器存储或安装包。本机 ~/.local/share/pagefold/analysis-config.json 可指定 model、baseURL、envFile。密钥文件必须是 0600，baseURL 必须为 HTTPS。无配置时说明缺少 API 配置，并保留 MCP 与本地建议入口。

模型接收短编号而非 Chrome 长编号，通过 JSON Schema 要求每页一个分类编号，再映射回真实标签 ID。90 秒超时、输出格式错误、遗漏或取消时原方案保留。最多一个任务在进行；取消会中止请求，但服务端已经消耗的额度无法退回。模型文本不作为指令执行。纯网址和数字论文标题没有已知分类时会留待补充线索，不猜测题目。

接入步骤见 README。不同服务与模型的兼容性需要自行验证；自动测试使用模拟服务检查格式、覆盖率、错误处理与预览流程。
